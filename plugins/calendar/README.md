# Calendar (CalDAV)

OpenClaw tool plugin for any CalDAV calendar: self-hosted Radicale, iCloud, Fastmail, Nextcloud, mailbox.org, Posteo and others.

Config: `serverUrl`, `username`, `password` (an app-specific password), and an optional `calendarName` default. `linux/05-plugins.sh` sets these for you.

## Build

```bash
npm install
npm run plugin:build
```
